About Me

Hi!! I am Irtaza, a 17-year-old high school student from Islamabad, Pakistan. I love everything tech! When I am not coding or tinkering with electronics, I enjoy editing videos, and playing table tennis. I also love nature, and books, and books in nature! And Pokémon.
I'm always happy to talk about computers and programming. Welcome to my portfolio!

Some things I have done

  • Reviewed and provided feedback on over 1300 technical projects submitted by teens worldwide for Summer of Making, an event by Hack Club and GitHub.
  • Hosted the SOM game jam for a community of 18k+ high schoolers around the globe!
  • Organised Borked (site), a game Web Jam for 6.7k teens! High Schoolers had to build a website with the worst UI possible!

Skills, Methodologies, and Tools

  • Programming/Scripting Languages: JavaScript, TypeScript, C#, C++, Python, HTML, CSS, Lua
  • Web Development Frameworks: React, Astro
  • Frontend: HTML, CSS, JavaScript, React, Bootstrap
  • Backend: Node.js, Express.js
  • PCB Design: KiCAD, EasyEDA
  • Hardware: CircuitPython, Raspberry Pi, MicroPython, Arduino
  • Database: MongoDB, Airtable
  • Game Development: Unity, Love 2D, Phaser.js, Pygame
  • Project Management: Trello
  • Source Code Management: Git, GitHub
  • Communication: Slack, Zoom
  • Video Editing: Adobe Premiere Pro, Adobe After Effects
